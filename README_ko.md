# AgentGit

[🇺🇸 English Version](./README.md)

AgentGit은 AI 에이전트가 만든 코드 변경 사항을 빠르게 검토할 수 있도록 설계된 TUI(터미널 사용자 인터페이스) 도구입니다. 에이전트의 요청 로그와 Git 히스토리를 시간축으로 연결하여, 모든 커밋과 미커밋 변경 사항 뒤에 숨겨진 "이유"와 "과정"을 쉽게 파악할 수 있게 돕습니다.

## 🚀 주요 기능

- **요청 그래프(Request Graph)**: AI 에이전트의 요청과 Git 변경 집합(changeset)의 관계를 하나의 타임라인에서 시각화합니다.
- **시간축 기반 연결**: Claude, Gemini, Codex 등의 요청 로그를 분석하여 해당 요청 이후 발생한 커밋과 자동으로 연결합니다.
- **단계별 탐색**:
  - **화면 1 (변경 집합)**: 전체적인 작업 흐름과 요청 이력을 탐색합니다.
  - **화면 2 (파일 목록)**: 선택한 변경 집합에 포함된 수정 파일들을 확인합니다.
  - **화면 3 (Diff)**: 키보드 조작으로 상세한 코드 차이(diff)를 검토합니다.
- **멀티 에이전트 지원**: 주요 AI 제공자의 로그를 파싱하여 현재 저장소와 관련된 요청만 필터링하여 보여줍니다.

## 🛠 작동 원리

AgentGit은 "시간축 기반 연결" 규칙을 사용하여 요청과 코드 변경을 연관시킵니다:
1. **커밋**: 이전 커밋과 현재 커밋 사이에 발생한 요청들을 해당 커밋에 연결합니다.
2. **워킹 트리(Working Tree)**: 마지막 커밋 이후에 발생한 요청들을 미커밋 변경 사항과 연결합니다.

*참고: 이 연결은 타임스탬프와 세션 컨텍스트를 기반으로 하며, 절대적인 인과관계 증명보다는 빠른 검토를 돕는 목적으로 설계되었습니다.*

## ⌨️ 주요 조작법

- `Up/Down`: 목록 이동 또는 Diff 스크롤.
- `Enter / Right`: 단계 진입 (변경 집합 -> 파일 목록 -> Diff).
- `Esc / Left`: 이전 화면으로 돌아가기.
- `r`: 로그 및 저장소 상태 새로고침.
- `q`: 종료.

## 📦 설치 방법

```bash
# 저장소 클론
git clone https://github.com/minkuik/agentgit.git
cd agentgit

# 빌드 및 설치
go build -o agentgit main.go
```

## 📖 사용법

Git 저장소 내부에서 `agentgit`을 실행하세요:

```bash
./agentgit
```

또는 특정 경로를 지정할 수 있습니다:

```bash
./agentgit /path/to/your/repo
```
